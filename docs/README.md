# Documentation

Maintained documentation for version 2.0:

- [Usage guide](USAGE.md): web workflows, input schema, output fields, local
  setup, and model export.
- [Frequently asked questions](FAQ.md): model choice, validation metrics,
  privacy, scope, and responsible use.
- [Deployment guide](../app/DEPLOYMENT_GUIDE.md): container and hosting notes
  for maintainers.

Pre-final working notes are stored in [`archive/`](archive/README.md). Those
files document project history and can contain superseded model names or
metrics.

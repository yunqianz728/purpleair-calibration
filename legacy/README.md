# Legacy research prototypes

This directory preserves code used during earlier model exploration and
release preparation. It includes the superseded temperature-stratified
calibration prototype, historical feature/download utilities, its research
environment, and one-off Zenodo upload scripts.

The final manuscript and public application use the single Temporal-National
paper model plus the separately validated sensor-only deployment models in
[`../app/`](../app/). Legacy modules are retained for provenance and are not
part of the maintained application interface.
